# stripflux

Strip CSV/TSV flux tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/stripflux/

## Install / run

```bash
git clone https://github.com/theworker02/stripflux.git
cd stripflux
node src/cli.js
node --test
```
